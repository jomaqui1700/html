# Ganadera San Ramón

Aplicación web para gestión separada de Café y Ganado, con inventarios independientes, gastos, peones, cosecha, tratamientos, aplicaciones y reportes.

## Stack
- Next.js
- Supabase
- Vercel

## Base de datos
Proyecto Supabase: Ganadera San Ramón.

La aplicación usa únicamente variables públicas del cliente Supabase en el navegador. Nunca se debe incluir una `service_role` o clave secreta en el frontend.
